# agentevents

Documentation for [agentevents](https://github.com/Charlesreilly0/agentevents), a Python library for event-driven communication between agents.

This wiki is generated from the `docs/` folder in the repository and is read-only — edits here will be overwritten. To change documentation, open a pull request against `docs/` in the repository.

- **[API reference](api)** — `Event`, `EventBus`, `InMemoryEventBus`, `RedisEventBus`, pattern matching, typed subscriptions, backpressure, and exceptions.
- **[Implementing a new EventBus backend](backend-guide)** — what's reusable across backends, what's backend-specific, and what a new backend (NATS, Kafka, Redis Streams, ...) needs to implement.

For installation, a quickstart, and contributing guidelines, see the [repository README](https://github.com/Charlesreilly0/agentevents#readme) and [CONTRIBUTING.md](https://github.com/Charlesreilly0/agentevents/blob/main/CONTRIBUTING.md).
